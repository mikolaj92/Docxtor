# Docxtor 0.18.0

This release includes the following changes:

- Tracked insert, delete, and replace wrap the characters named by the
  caller's offset even when that span sits in the middle of an existing
  comment, revision, bookmark, or hyperlink. The operations still refuse,
  and leave the file unchanged, when the range cannot be mapped onto the
  paragraph's text. Drawings and other real opaque content stay fail-closed.
- Comment add/update/remove, native tracked insert/delete/replace, and
  in-place `publish()` stay public only on the open handle.

Docxtor does not add a second review markup format.
