# Docxtor 0.14.3

This release includes the following change:

- **#188:** Publication marks preserve existing footer content and package
  relationships when they are added. Existing fields, drawings, linked-footer
  state, and other footer structure remain intact; the mark is appended only
  when that footer does not already contain it.

Publication marks remain metadata and footer mutations. They do not change
LibreOffice's pagination behavior or provide a fixed-layout guarantee.
