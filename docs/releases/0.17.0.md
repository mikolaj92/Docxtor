# Docxtor 0.17.0

This release includes the following changes:

- Repeated `DocxDocument.add_comment` on the same sentence is valid native
  Word markup. A second (or third) comment on the same span, or on a span
  that already contains `w:commentRangeStart` / `w:commentRangeEnd` markers,
  adds another comment without dropping or rewriting earlier ones.
- Comment add/update/remove, native tracked insert/delete/replace, and
  in-place `publish()` stay public only on the open handle.

Docxtor does not add a second review markup format.
