# Docxtor 0.16.0

This release includes the following changes:

- Comment add/update/remove, native tracked insert/delete/replace, and
  in-place publish are public only on the open `DocxDocument` handle.
  Import those operations from `docxtor` as handle methods, not as
  byte-level functions. `publish()` with no arguments writes back to the
  path passed to `DocxDocument.open` through `publish_docx`. Opened-from-bytes
  handles fail closed. Tracked edits remain native `w:ins` / `w:del`.
- Unused whole-paragraph `add_paragraph_comment` and
  `mark_paragraph_revision` helpers are gone. They were not on the handle
  and had no production callers.

Docxtor does not add a second review markup format.
