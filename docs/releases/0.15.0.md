# Docxtor 0.15.0

This release includes the following changes:

- `update_comment` rewrites one Word comment body by id and keeps comment
  identity, range anchors, authorship, parent/reply identity, and thread
  sidecar parts.
- `DocxDocument` is the open DOCX handle for that same file: `add_comment`,
  `update_comment`, `delete_comment` / `remove_comments`, `insert_revision`,
  `delete_revision`, and `replace_revision`. Tracked edits remain native
  `w:ins` / `w:del`.

The existing byte-level comment and revision functions stay public. Docxtor
does not add a second review markup format.
