# Docxtor 0.15.0

This release includes the following changes:

- `update_comment` rewrites one Word comment body by id and keeps comment
  identity, range anchors, authorship, parent/reply identity, and thread
  sidecar parts.
- `DocxDocument` is the open DOCX handle for that same file: `add_comment`,
  `update_comment`, `remove_comments`, `insert_revision`, `delete_revision`,
  `replace_revision`, and `publish()`. `publish()` with no arguments writes
  back to the path passed to `DocxDocument.open` through `publish_docx`.
  Opened-from-bytes handles fail closed. Tracked edits remain native
  `w:ins` / `w:del`.

Docxtor does not add a second review markup format.
