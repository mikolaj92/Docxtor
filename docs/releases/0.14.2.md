# Docxtor 0.14.2

This release includes the following changes:

- **#183:** Whole-paragraph tracked insertions inherit the anchor paragraph's explicit
  style and direct formatting, plus usable formatting from its first eligible
  text run. Empty run properties fall back to paragraph-mark formatting and
  then to the paragraph style's character defaults.
- **#184:** `BodyAppendix` supports optional pagination hints to keep appendix paragraphs
  together, keep its heading with the next paragraph, or keep its first
  paragraph with the following paragraph. All three options default to `False`.

Pagination controls are OOXML hints, not fixed-layout guarantees. In
LibreOffice, a paragraph taller than a page can still split or continue onto
another page, and an oversized following paragraph can cause LibreOffice to
relax a keep-with-next link. See [Body appendix pagination](../appendix-pagination.md)
for the option semantics and limits.
